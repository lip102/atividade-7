1-capacidade de mudança: a variável altera seu valor em tempo real para responder ao ambiente, enquanto a constante (ou parâmetro) permanece fixa durante o funcionamento

2-O comando leia() é usado em linguagens de programação educacionais, como o Portugol, para receber dados digitados pelo usuário durante a execução do programa.

3-Os operadores lógicos (E, OU, NÃO) são a base da automação de segurança em máquinas, atuando como o "cérebro" que avalia as condições de entrada (sensores, botões, cortinas de luz) para decidir se a máquina pode operar ou se deve parar.

4-Uma Estrutura de Repetição (ou laço/loop) é um conceito da lógica de programação que permite executar um conjunto de instruções várias vezes, sem precisar reescrever o mesmo código repetidamente. Ela é definida pela necessidade de repetir uma tarefa até que uma condição específica seja satisfeita, garantindo eficiência e automação.

5-Para: É usado quando você sabe exatamente quantas vezes o bloco de código deve ser executado (iterações definidas).
Enquanto : É usado quando você não sabe quantas vezes o bloco de código será executado, mas sabe a condição que deve ser atendida para parar (iterações indefinidas).

6-Um loop infinito (ou laço sem fim) é uma sequência de instruções de código que se repete indefinidamente, pois a sua condição de parada nunca é atingida ou jamais se torna verdadeira. Em termos simples, é um programa preso em um ciclo repetitivo que não tem previsão para acabar, consumindo recursos processamento de forma contínua.
Embora possa ser usado intencionalmente em certas aplicações (como no loop principal de um jogo que espera por comandos), um loop infinito acidental é um erro de lógica de programação comum.

7-Os operadores de divisão inteira (// em Python, ou div em outras linguagens) e módulo (%) são ferramentas fundamentais na programação para dividir um conjunto de dados grande (um total de itens, ou dataset) em grupos menores e organizados (lotes), especialmente quando se processa arquivos, banco de dados ou paginação de resultados.

8-A identação (ou recuo) do código é essencial em projetos colaborativos porque transforma o código-fonte em um documento legível, reduzindo o tempo que os desenvolvedores gastam para entender a lógica criada por terceiros. Ela organiza visualmente a hierarquia dos blocos de código (loops, condicionais, funções), facilitando a identificação de erros e a manutenção

9-A estrutura condicional composta (se / senão ou if / else) é fundamental para sensores, pois permite que um sistema tome decisões baseadas em dados do ambiente. Diferente da condicional simples, a composta executa uma ação se a condição for verdadeira e outra ação caso ela seja falsa.

10-A documentação de código com comentários no ambiente profissional é crucial para aumentar a legibilidade, facilitar a manutenção e aprimorar a colaboração entre equipes, funcionando como uma ferramenta de comunicação que explica o "porquê" das decisões técnicas, não apenas o "o quê".
